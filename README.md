# 型构 · Frame Studio

### 铝型材 3D 结构设计与组装工作台

**型构（Frame Studio）** 是一款基于浏览器的可视化铝型材三维建模工具，将结构设计、材料选型、零件装配、加工编辑、尺寸测量与初步受力分析整合到同一工作空间。

面向 DIY 爱好者、创客、设计师及小型加工工作室，帮助用户更直观地从结构构想到三维模型，并生成用于备料和加工沟通的参考数据。

## 核心功能

### 01 · 三维建模与结构编辑

- **自由绘制**：在三维空间中创建铝型材，支持 X / Y / Z 轴向约束、精确长度输入及连续绘制。
- **参数化框架**：提供工作台、立方框架、三层置物架、龙门支架等基础模板，可自定义整体尺寸和型材规格。
- **智能吸附**：识别型材端点、表面及对齐参考，辅助构件定位与连接。
- **精确编辑**：支持移动、旋转、复制、多选、删除、长度调整及坐标输入。
- **结构分层**：可在现有框架中增加分隔横梁，辅助多层结构设计。

### 02 · 材料库与构件管理

- **铝型材库**：内置多种欧标铝型材规格及截面示意，提供槽宽、槽深、中心孔等参考参数。
- **板材材料**：包含亚克力、木板、饰面板及铝板，支持厚度、颜色与安装方式设置。
- **扩展材料**：支持光轴、钢丝拉索等结构材料。
- **辅助配件**：支持层板托、型材端盖、脚轮等配件的放置与调整。

### 03 · 智能连接与组装

- **连接件安装**：支持在型材交接位置添加连接件，并根据安装位置匹配对应的结构规格。
- **连接关系识别**：显示构件接触与连接状态，辅助检查尚未安装的连接位置。
- **智能连接管理**：提供批量补齐连接件功能；当构件不再满足原有连接关系时，自动清理相关连接件。
- **干涉检测**：识别部分构件及连接件之间的空间干涉，并提供定位与调整辅助。
- **组装示意**：可按型材、板材、连接件等类别查看装配定位信息，并通过浏览器打印或保存 PDF。

### 04 · 板材设计与加工

- **多种安装方式**：支持矩形覆盖式、嵌平式、嵌入式和轮廓覆盖式安装。
- **自由调整尺寸**：可以从单条型材边生成面板，并通过边缘拖动或数值输入调整尺寸。
- **板材裁切**：支持直线裁切、外轮廓编辑和顶点调整。
- **板材挖空**：支持矩形孔、圆孔及多边形开口，并可输入孔位尺寸。
- **连接件避让**：提供板材与连接件的自动避让参考，减少装配干涉。

### 05 · 型材切割与打孔加工

- **型材切割**：支持 45° 斜切及自定义角度切割，提供切割方向预览和拼角对齐。
- **打孔加工**：支持通孔、沉头孔、盲孔及攻丝加工设置。
- **精确孔位编辑**：在三视图中查看型材孔位，支持拖动孔位、输入位置尺寸及加工深度。
- **端面加工**：支持型材端面中心孔及相关攻丝参数设置。
- **加工清单**：可导出打孔与攻丝 CSV 数据，用于加工信息整理和沟通。

### 06 · 抽屉、滑轨与扩展结构

- 支持创建矩形虚拟抽屉，或将多根型材组合为抽屉框架。
- 支持绑定固定外框，并调整抽屉尺寸、位置及抽出方向。
- 提供滑轨适配参数与抽屉抽出预览。
- 支持光轴支座、光轴及钢丝拉索等扩展构件。

### 07 · 尺寸测量与视图控制

- **智能测量**：查看构件尺寸及空间距离。
- **两点测量**：在三维空间中选取端点或角点，测量实际距离及各轴向差值。
- **爆炸视图**：临时分离模型构件，便于观察内部结构和装配关系。
- **视角控制**：支持透视、正交视图、旋转、平移、缩放及画面居中。
- **快捷操作**：提供键盘快捷键、快速命令搜索及上下文快捷轮盘。

### 08 · 结构受力分析

软件内置两种初步结构计算工具：

**单根横梁受力估算**

针对水平型材设置载荷、跨度、材料及支承条件，估算弯曲应力、挠度等指标。

**整架受力分析**

基于线弹性空间梁模型，设置载荷、固定约束与材料参数，对框架整体进行初步计算。

- 正应力与位移热力图
- 最大应力与变形量
- 固定点反力
- 高应力构件定位
- 文本计算报告导出

**注意：** 受力结果属于简化工程估算，并非完整实体有限元验证。计算未完整覆盖连接件真实承载、结构屈曲、局部应力、加工孔削弱及实际施工误差，不得直接作为额定承重或结构安全依据。

### 09 · 渲染与方案展示

- 支持切换实时渲染模式。
- 可调整金属与板材材质、灯光方向、曝光及背景。
- 支持导出 PNG 模型预览图和渲染效果图。
- 可生成适用于外部 AI 图生图工具的渲染提示词。

### 10 · 项目管理与文件导出

- **本地项目管理**：支持创建、切换、重命名和删除项目，自动保存到当前浏览器。
- **JSON 工程文件**：支持导出项目文件，便于备份和继续编辑。
- **物料清单**：统计型材、板材及相关配件信息，支持 CSV 导出。
- **加工数据**：导出孔位及攻丝相关参数。
- **参考图辅助建模**：可借助外部 AI 将参考图片转换为符合指定格式的 JSON，再导入为可编辑项目。

## 使用方式

当前版本采用单 HTML 文件形式，使用支持 WebGL 的现代浏览器打开 `aluminum-studio.html` 即可进入建模工作台。

项目默认保存在当前浏览器的本地存储中。建议定期导出 JSON 文件进行备份，避免清除浏览器数据后丢失设计。

## 使用说明

型构旨在辅助铝型材结构设计、装配规划与备料。

软件中的型材截面、材料参数、连接件尺寸、加工数据和受力计算可能包含示意值或简化假设。实际制作前，应根据采购厂家图纸、零件实物及工程要求复核尺寸、连接方式与结构安全性。
